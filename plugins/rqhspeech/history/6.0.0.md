# rqhspeech 6.0.0

- 版本号：6.0.0
- 发布日期：2026-10-17
- 状态：当前版本

## 概述

群聊发言统计插件，支持日榜、周榜、月榜、季榜、年榜、个人发言统计、每日签到、用户管理、白名单与数据归档。本版本起全部业务数据使用插件目录内的 JSON 文件存储，不再依赖数据库。

## 变更内容

1. 存储层改为纯 JSON：发言统计、插件配置、签到数据均保存在插件 `data` 目录内
2. 移除 SQLite：删除 `sdk/storage/speech_db.py`、`data/speech.db`、`data/speech_test.db`
3. `sdk` 回归框架层，不再包含任何 rqhspeech 业务实现
4. 用户数据迁移：96 个用户、4,906,764 条发言完整导出为 JSON
5. 数据文件按用户拆分，写入采用按用户加锁 + 临时文件原子替换
6. 修复 `USE_WHITELIST_MODE` 从配置加载后被重置为 `false` 的问题
7. README、plugin.json、main.py 版本号同步更新为 6.0.0

## 数据目录

```
data/
├── users/user_<user_id>.json   # 用户发言日明细、周聚合与摘要
├── config/speech_config.json   # 白名单、管理员、操作员、白名单模式
├── checkin/<user_id>.json      # 签到数据
└── archives/                   # 归档的排行榜 JSON / CSV 与备份
```

## 迁移与兼容

- 命令、权限与返回格式保持与 5.1.0 一致
- 迁移校验结果：用户数、总发言数、日明细逐条一致；排行榜计数一致
- 升级后旧数据库文件已删除，请保留并备份 `data/users/` 下的 JSON 文件
- 不支持回退到 5.1.0 的 SQLite 存储
