# rqhspeech 5.1.0

- 版本号：5.1.0
- 记录日期：未记录（建档时依据代码注释补录）
- 状态：历史版本，已被 6.0.0 取代

## 概述

群聊发言统计插件，支持日榜、周榜、月榜、季榜、年榜、个人发言统计、每日签到、用户管理、白名单与数据归档。

## 变更内容

1. 修复 group_id 类型不一致问题（统一转为字符串）
2. 修复设置用户名乱码键名 bug
3. 统一命令格式（查询发言）
4. 封装公共函数（获取用户名、加载/保存数据）
5. 优化周切换函数参数
6. 使用 logging 模块替代手写日志
7. 代码结构拆分，更易维护
8. 添加管理员权限检查
9. 管理器全局单例，避免重复实例化
10. 命令处理函数独立到 command_handler.py
11. 支持按年分层的目录结构
12. 支持操作员权限管理
13. 签到功能迁入，签到数据以 JSON 文件存放于插件 `data/checkin` 目录

## 存储方式

- 发言统计：SQLite（`data/speech.db`，表 `users` / `daily_records` / `weekly_agg`）
- 插件配置：SQLite `config` 表
- 签到数据：`data/checkin/<user_id>.json`
- 运行日志：`logs/<年>/speech_<日期>.log`

## 升级说明

升级到 6.0.0 时，原有 SQLite 数据会导出为 JSON 并停用数据库，详见 [6.0.0](6.0.0.md)。
