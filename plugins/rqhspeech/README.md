# rqhspeech 插件

一个基于 NcatBot 的群聊发言统计管理程序，支持日榜、周榜、月榜、季榜和年榜等多种维度的发言统计与排行。

数据全部以 JSON 文件保存在插件自己的 `data` 目录内，不依赖任何数据库；`sdk` 仅提供框架能力，不包含本插件的业务实现。

## ✨ 主要功能

- **多维度排行榜**：支持日榜、周榜、月榜、季榜、年榜及历史榜单查询
- **个人发言统计**：实时查看今日、本周、本月及本年度的发言数据
- **每日签到**：群聊/私聊均可签到，连续签到有额外积分，签到数据以 JSON 文件保存在插件 `data/checkin` 目录
- **用户管理**：自动注册、自定义用户名、管理员权限控制
- **白名单模式**：支持指定群聊使用或全群开放
- **数据归档**：自动备份与历史数据归档，支持 JSON 和 CSV 格式导出
- **详细日志**：自动记录每日发言明细，方便追溯与分析
- **按年分层目录**：数据按年份自动分层存储，便于管理

## 🚀 快速开始

### 环境要求

- Python 3.8+
- NcatBot 框架

### 安装步骤

1. 将 `rqhspeech` 文件夹放入 NcatBot 的 `plugins` 目录下
2. 确保已安装依赖库（如有）
3. 重启 NcatBot 加载插件

### 初始配置

插件首次运行会自动生成 `data/config/speech_config.json` 配置文件：

```json
{
  "allowed_groups": [],
  "admin_users": [],
  "operator_users": [],
  "use_whitelist_mode": false
}
```

- `allowed_groups`: 允许使用插件的群号列表
- `admin_users`: 管理员 QQ 号列表
- `operator_users`: 操作员 QQ 号列表
- `use_whitelist_mode`: 是否开启白名单模式（true=仅白名单群可用，false=所有群可用）

## 📂 目录结构

```
rqhspeech/
├── main.py                # 插件主入口（仅负责框架对接）
├── speech_config.py       # 配置管理类
├── data_manager.py        # 数据管理模块（纯 JSON）
├── command_handler.py     # 命令处理器
├── archive_manager.py     # 归档管理器（日榜+周榜归档）
├── checkin_manager.py     # 签到管理
├── __init__.py            # 模块入口
│
├── data/                  # 数据存储根目录（全部为 JSON）
│   ├── users/             # 用户发言明细与周聚合
│   ├── checkin/           # 签到数据
│   ├── config/            # 插件配置
│   │   └── speech_config.json
│   └── archives/          # 归档数据
│       ├── rankings/      # 排行榜JSON（按年分层）
│       ├── csv/           # 排行榜CSV（按年分层）
│       └── backups/       # 数据备份（按年分层）
│
└── logs/                  # 运行日志（按年分层）
```

## ⚙️ 高级配置

### 排行榜人数限制

在 `speech_config.py` 中可调整各榜单显示人数：

```python
self.RANKING_DAILY_TOP_N = 15   # 日榜前15名
self.RANKING_WEEKLY_TOP_N = 10  # 周榜前10名
self.RANKING_MONTHLY_TOP_N = 10 # 月榜前10名
self.RANKING_SEASONAL_TOP_N = 10 # 季榜前10名
self.RANKING_YEARLY_TOP_N = 10  # 年榜前10名
```

### 数据归档策略

- **日榜归档**：管理员发送 `自动归档` 命令，自动检查并归档上次备份后的所有日期，生成 JSON/CSV 到 `data/archives/rankings/` 目录
- **周榜归档**：支持命令行手动建榜与自动归档：
  ```bash
  python archive_manager.py --weekly           # 归档本周
  python archive_manager.py --weekly-date W19  # 归档指定周
  python archive_manager.py --weekly-auto      # 自动归档所有未归档周
  ```
- **备份机制**：归档前自动在 `data/archives/backups/` 下备份用户数据
- **文件格式**：同时生成 `.json`（详细数据）和 `.csv`（表格数据）两种格式
- **排行榜数据源**：所有榜单（日/周/月/季/年）实时从用户文件读取

## 🔧 开发说明

### 代码架构

本版本采用模块化设计，各模块职责明确：

1. **main.py**：仅负责与 NcatBot 框架对接，不包含业务逻辑
2. **speech_config.py**：统一管理所有配置常量和目录结构
3. **data_manager.py**：纯 JSON 数据读写与统计聚合
4. **command_handler.py**：处理所有命令逻辑
5. **archive_manager.py**：负责数据归档和备份

### 数据存储

- 所有业务数据均为插件目录内的 JSON 文件，不使用数据库
- 用户文件：`data/users/user_<user_id>.json`（日明细 + 周聚合 + 摘要）
- 配置文件：`data/config/speech_config.json`
- 签到文件：`data/checkin/<user_id>.json`
- 写入采用临时文件 + 原子替换，并按用户加锁，避免并发损坏

### 权限体系

- **Admin（管理员）**：拥有最高权限，可管理白名单、用户、管理员和操作员
- **Operator（操作员）**：可执行部分管理命令（如自动归档、查看白名单）
- **普通用户**：可使用基础命令（注册、查看排行榜、查询发言等）

### 数据迁移

插件支持从旧版本自动迁移数据，迁移过程在首次加载时自动执行。
